# PitchQuill

PitchQuill is a high-performance, multi-channel data annotation and validation platform featuring real-time live-data-processing and instant-annotation capabilities.

PitchQuill is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PitchQuill.git`
2. `cd PitchQuill`
3. Install in editable mode: `pip install -e .`

## Configuration

PitchQuill is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
